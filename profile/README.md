## What is Dragonboon?

Dragonboon is a collection of **Godot-native development tools** built to make game creation faster, more flexible, and easier to maintain.

From a production-oriented project foundation to editor workflows and ready-to-integrate puzzle systems, each repository solves a specific problem. **Use the tools independently**—there is no required framework or all-in-one dependency.

## Projects

### [Nucleus](https://github.com/Dragonboon/Nucleus) — Game foundation

`Project template` · `Architecture` · `Reusable systems`

A production-oriented starting point for Godot projects, with composable core services, optional gameplay and production modules, and automated validation workflows.

[Repository](https://github.com/Dragonboon/Nucleus) · [Documentation](https://github.com/Dragonboon/Nucleus/tree/main/docs) · [Issues](https://github.com/Dragonboon/Nucleus/issues)

### [Atrium](https://github.com/Dragonboon/Atrium) — 3D room & dungeon authoring

`Editor plugin` · `3D tools` · `Procedural generation`

Create and edit 3D rooms and connected dungeons in the Godot editor, with deterministic layouts, collision-aware construction, and portable scene export.

[Repository](https://github.com/Dragonboon/Atrium) · [Documentation](https://github.com/Dragonboon/Atrium/tree/main/docs) · [Issues](https://github.com/Dragonboon/Atrium/issues)

### [Trispark](https://github.com/Dragonboon/Trispark) — Match-3 gameplay

`Gameplay plugin` · `2D puzzles` · `Configurable rules`

Build customizable match-3 boards using Godot Resources, with flexible movement and refill rules, presentation hooks, signals, and game-specific reactions.

[Repository](https://github.com/Dragonboon/Trispark) · [Documentation](https://github.com/Dragonboon/Trispark/tree/main/docs) · [Issues](https://github.com/Dragonboon/Trispark/issues)

### [JigsawG](https://github.com/Dragonboon/JigsawG) — Jigsaw puzzle toolkit

`Gameplay plugin` · `2D puzzles` · `Procedural pieces`

Create image-based jigsaw puzzles with procedural interlocking pieces, snapping and grouping, multiple play styles, optional assistance, and resumable puzzle state.

[Repository](https://github.com/Dragonboon/JigsawG) · [Documentation](https://github.com/Dragonboon/JigsawG/tree/main/docs) · [Issues](https://github.com/Dragonboon/JigsawG/issues)

## Getting started

1. **Choose a tool** based on what your game needs.
2. **Read its repository README** for supported Godot versions, installation steps, and integration boundaries.
3. **Try the included examples**, where available, before adapting the tool to your project.

Nucleus is a project foundation; Atrium, Trispark, and JigsawG are focused plugins. You can adopt only the parts that fit your game.

## How we build

We favor **Godot-native workflows**, small and composable systems, explicit dependencies, practical documentation, and validation that supports real-world development. The goal is to make the tooling useful without taking control away from the game developer.

## Contributing

Bug reports, ideas, and contributions are welcome. Open an issue in the **relevant project repository**, check its documentation, and review its contribution guidance before proposing changes.
